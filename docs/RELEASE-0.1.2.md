# 0.1.2 发布验收

日期：2026-10-05。0.1.2 聚焦运行效率、资源生命周期和可重复构建，保留既有模板、HTML 预览、完整思源黑体及 PDF 排版规则。本记录区分已完成的架构回归与递增版本后的最终发布核对，不代表社区审核通过。

## 已完成的架构回归

本轮在 macOS / Obsidian 1.13.7（安装器 1.12.4、Electron 39.7.0）使用隔离测试 Vault 和虚构样例验证。该轮宿主测试构建仍标记 0.1.1；以下是 0.1.2 所含重构的回归证据，不作为最终 0.1.2 下载附件验证记录。

| 验收项 | 结果 |
| --- | --- |
| 静态与构建 | ESLint、30 项自动测试、TypeScript、生产构建和安装包校验通过。 |
| 相同内容更新 | 首次预览后顺序发送 10 次相同内容：旧版额外渲染 10 次，重构版 0 次。 |
| 编辑器读取与突发更新 | 防抖窗口内 50 次延迟读取请求仅读取 1 次；50 次变更仅渲染 1 次，最终内容正确。 |
| 正确性 | 拒绝过期结果，相关图片变化触发更新，缺失照片在附件建立后恢复；导出保留点击时的快照。 |

本地原始证据位于 `evidence/architecture-20261005/`，包括 `before.json`、`after.json`、`comparison.json`、`release-host/host-results.json`、`release-host/pdf-results.json`、`release-host/pdfkit-results.json` 和 `visual-review.json`，均不入库。详细方法见[架构记录](ARCHITECTURE.md)。

## 安装和升级

[0.1.2 Release](https://github.com/gbs00/markdown2cv/releases/tag/0.1.2) 提供 `main.js`、`manifest.json`、`styles.css` 以及手动安装 ZIP。旧版用户先停用插件，替换 Vault 中 `.obsidian/plugins/markdown-to-cv/` 下的三个文件，再启用插件。无需修改简历 Markdown 或安装系统字体。

## 保留的约束

- 完整思源黑体 CN 2.005R 仍内嵌，`main.js` 超过 5 MB；Obsidian Sync Standard 无法同步该文件。
- PDF 仍依赖非公共 `@electron/remote`；macOS 已回归，Windows/Linux 未验收，Android/iOS 不支持。
- 真实中文输入法、第三方主题、长时间稳定性与真实用户任务仍需补充验收。
- 不承诺所有 Unicode 姓名用字或所有 ATS/提取器兼容；忽略 PDF `ActualText` 的提取器可能误读同形汉字。
- 本次改进不代表社区所有 warning 均已清除。英文说明、生产构建一致性及来源证明应由新版自动审核再次核对。
